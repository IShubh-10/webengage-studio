Timer Setup TMR-01

Design the creative in Dynamic Images first. Its {{placeholders}} still work — pass them on the timer URL and the artwork is personalised too.

600px is the safe width for email. Transparent artwork is flattened onto the colour above, because GIF transparency is unreliable across clients.

The deadline is read as wall-clock time in this zone, so daylight saving is handled for you.

Add ?uid={{user.id}} to the image URL. The first open records the start; later opens count down from it.

The largest unit shown absorbs everything above it — drop Days and 3 days becomes 72 hours.

The countdown never goes below zero. It swaps to this the moment the deadline passes — including mid-animation, if it runs out while someone is looking at it.

One frame per second, so 60 frames is a minute of animation. Drop the palette below 256 for a smaller file on flat artwork; leave it at 256 for photographs.

Parameter What it does
?end= A different deadline for this send. Epoch seconds, or 2026-12-31 23:59:59.
?tz= Read end in this zone. Merge the recipient's own: tz={{user.timezone}}.
?uid= Required for an evergreen timer — it is what the start time is remembered against.
?anything= Fills a {{placeholder}} in the creative, exactly as Dynamic Images does.
